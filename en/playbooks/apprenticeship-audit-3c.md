# Team apprenticeship audit: the 3Cs

> Practicum for Chapter 4, "The ladder is breaking: entry and middle roles."
> Based on Matt Beane's *The Skill Code*: challenge, complexity, connection.

Goal: check whether your team has removed the ladder that its next generation needs to grow.

## 1. Challenge: is the work hard enough to teach

| Question | Yes / no | What should change |
|---|---|---|
| Do new team members get tasks just above their current skill level? |  |  |
| Do they have safe tasks where they can make a mistake and review it? |  |  |
| Does AI help them learn instead of simply giving them a finished answer? |  |  |

## 2. Complexity: can the person see the whole process

| Question | Yes / no | What should change |
|---|---|---|
| Does the new team member understand why the task matters and who needs the result? |  |  |
| Can they see the full path from request to decision and how their task fits? |  |  |
| After routine work was automated, did the team keep hands-on reviews of real cases? |  |  |

## 3. Connection: is there a relationship with an expert

| Question | Yes / no | What should change |
|---|---|---|
| Does someone review the new team member's work and give useful feedback? |  |  |
| Is there enough trust to let the person do the work instead of only watching? |  |  |
| Do senior staff get time and recognition for developing other people? |  |  |

## 4. Overall risk

| Level | Sign | What to do |
|---|---|---|
| Low | Most of the 3Cs are healthy | Decide which tasks you can automate without weakening learning |
| Medium | One of the 3Cs is weak | Restore the missing part during the next quarter |
| High | New people only watch or edit completed work | Assign learning tasks and mentors. Otherwise, your skill pipeline is already broken |
