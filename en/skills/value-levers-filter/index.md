# Skill: three value levers filter

> A zero-install tool for **Volume 1, Chapter 2**, "The New Price of Intelligence." It runs in your
> browser, calculates on your device, and sends no data anywhere. Code license: MIT.

This is the interactive version of the [Three Value Levers Filter](../../playbooks/value-levers-filter.md).
Use it to see which lever creates value in one task and whether cheap AI is removing that value.

<a class="md-button md-button--primary" href="tool.html">Open the tool</a>

## What it does

- You choose **one** task or product.
- You select a lever (new sales and growth / cost savings / attention and trust), then answer two
  questions: can cheap AI already do it, and does it set you apart?
- The tool shows whether this is `output` that is becoming cheaper or an `outcome` worth strengthening.
  It also gives you one move: what AI can do and what you should keep.
- You can copy the result and give it to an AI assistant.

## How to use it

1. Open the tool, name one task, and answer the questions honestly.
2. Copy the result.
3. Tell AI: "Here is my analysis using the three value levers. Suggest one move and what I should
   check." Ask for options, not a finished decision.

## Discipline

This filters direction. It is not a money calculator and does not calculate ROI or savings. It shows
where value is becoming cheaper and where it remains yours. Calculate exact figures separately from
your own data.

## Chat version if you cannot use the browser tool

```text
Help me analyze ONE task using the "three value levers" model from *When Intelligence Became Cheap*,
Volume 1, Chapter 2. Task: [name one].
Choose one lever: new sales or growth (something others cannot offer) / cost savings / attention and
trust. Answer two questions: (1) can cheap AI already do this almost completely, partly, or not at all;
(2) does it set me apart in a unique, moderate, or common way?
Tell me whether this is output that is getting cheaper and should be automated to free time, or an
outcome that I should strengthen through ownership, judgment, trust, or attention. Give me ONE move:
what AI should handle and which outcome I should keep. Avoid hype and promises of money.
```
