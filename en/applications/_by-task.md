# Start with the task if your profession is missing

> There are many professions, but most contain similar tasks. Find yourself through the work that
> takes up your week. **Date: 2026-06.** The baskets move over time, so review them again. Each role
> page has the full analysis.

| Task | Basket (2026-06) | Where to read more |
|---|---|---|
| Reports and summaries | 🟢→🟡 AI draft, human conclusion | [accountant](buhgalter.md), [analyst](analitik.md) |
| Documents and contracts | 🟡 draft + review | [lawyer](lawyer.md) |
| Articles, posts, and newsletters | 🟢 drafts, 🔴 voice and strategy | [marketer](marketolog.md) |
| Customer correspondence | 🟡 tone options, person decides | [sales](sales-b2b.md), [support](podderzhka.md) |
| Presentations | 🟢 structure and draft | marketer, any role |
| Data and spreadsheet analysis | 🟡 hypotheses + verification | [analyst](analitik.md), accountant |
| Search and research | 🟢 first pass, links must be checked | any role |
| Meeting transcription | 🟢 notes + action items | any role |

**The principle is the same everywhere:** a clear input and a verifiable output belong to the machine.
Ambiguity, responsibility, trust, and live communication belong to the person. Chapter 2 explains where
to shift your effort.
