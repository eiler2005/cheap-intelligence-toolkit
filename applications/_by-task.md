# Вход по задаче (не нашли свою профессию?)

> Профессий много, но задачи у всех похожи. Найдите себя по делу, которое занимает вашу неделю.
> **Дата: 2026-06.** Корзины ползут — пересматривайте. Полный разбор — на странице профессии.

| Задача | Корзина (2026-06) | Где разобрано подробнее |
|---|---|---|
| Отчёты и сводки | 🟢→🟡 черновик ИИ, вывод человек | [бухгалтер](buhgalter.md), [аналитик](analitik.md) |
| Документы и договоры | 🟡 черновик + проверка | [юрист](lawyer.md) |
| Тексты, посты, рассылки | 🟢 черновики, 🔴 голос/стратегия | [маркетолог](marketolog.md) |
| Переписка с клиентами | 🟡 варианты тона, человек решает | [sales](sales-b2b.md), [поддержка](podderzhka.md) |
| Презентации | 🟢 структура и черновик | маркетолог, любой |
| Анализ данных/таблиц | 🟡 гипотезы + проверка | [аналитик](analitik.md), бухгалтер |
| Поиск и ресёрч | 🟢 первичная подборка (ссылки проверять) | любой |
| Расшифровка встреч | 🟢 протокол + задачи | любой |

**Принцип везде один:** чёткий вход + проверяемый выход = территория машины; неоднозначность,
ответственность, доверие, живая коммуникация = территория человека. Куда переносить вес — гл. 2.
