# Разработчик: что автоматизировать и чем

> Блок: **ИТ и продукт**. Хаб профессии. **Проверено: 2026-08-18.** Инструменты не статичны. Глобальные —
> из РФ через VPN/зарубежную карту или [агрегатор](https://cheap-intelligence.vercel.app/watch/tools-map); приватный код/секреты — только
> локально/в своём контуре. Источники разбора — внизу страницы.

## В один взгляд
ИИ силён в коде: генерация, тесты, ревью и multi-file правки быстро переходят в режим «агент делает
черновик». Но «написать код» ≠ «отвечать за работающий продукт». Ценность смещается к архитектуре,
проверке, безопасности и ответственности за прод.

!!! info "📊 Что говорят данные (GDPval · Anthropic Economic Index · O*NET)"
    - **Может (GDPval):** генерирует код, тесты, доки; агентно делает multi-file изменения.
    - **Делают (AEI):** Computer & Mathematical — один из наиболее экспонированных классов задач:
      около трети всех диалогов в Claude.ai и почти половина трафика через API.
    - **Важная поправка 2026 года:** если скорректировать покрытие задач на долю успешных выполнений,
      разработчики оказываются затронуты **относительно слабее**, чем следует из одного покрытия
      (сильнее всех — операторы ввода данных и рентгенологи). Высокая экспозиция задач ≠ высокая
      замена профессии.
    - **Сколько это уже в реальном коде:** к февралю 2026 года на один только Claude Code приходилось
      около **4% всех публичных коммитов на GitHub** — примерно 135 тыс. в день.
    - **Что происходит со спросом:** вакансий с требованием опыта работы с ИИ-инструментами
      разработки стало больше примерно **на 340%** с января 2025 по январь 2026 года, а вакансий на
      чистую реализацию — меньше примерно **на 17%**.
    - **Режим:** 🔴 высокое замещение задач — junior-задачи уходят первыми; остаётся архитектура,
      безопасность, ответственность за прод. → [Полный разбор по данным](_super-analysis.md) · [📋 ИИ-стратегия роли](strategy/razrabotchik.md).

## Что автоматизировать в первую очередь

1. **Бойлерплейт, тесты, документация.** Рутина с чёткими паттернами — отдать (с ревью).
2. **Объяснение и навигация по коду.** «Объясни этот модуль / где рискованные места».
3. **PR-саммари и авто-ревью.** Черновые комментарии к pull request (финальное ревью — человек).
4. **Агентные задачи.** План→код→тесты→правка, multi-file (Cursor Composer, Copilot agent).
5. **Миграции и security-скан.** Перевод между версиями языка, инлайн-сканирование уязвимостей.

## Разбор по задачам: что отдать ИИ, что проверить

| Задача (O*NET) | Отдать ИИ — как/чем | Оставить себе / проверить | Промпт-старт |
|---|---|---|---|
| Бойлерплейт/тесты | генерация по образцу | краевые случаи, прогон тестов | `Каркас функции X + тесты на краевые случаи` |
| Объяснение кода | разбор модуля | рискованные места | `Объясни модуль и отметь рискованные места` |
| Ревью PR | черновые комментарии | финальное ревью, безопасность | — |
| Новая фича | агент: план→код→тесты | ревью диффа, прод-готовность | `Реализуй по критериям приёмки, покажу дифф` |
| Дебаг | гипотезы по симптомам | воспроизвести, исправить | `2 вероятные причины бага и как проверить каждую` |

> Код в прод — только через ваше ревью. Секреты не вставлять; приватное — локальные модели.

    - **Claude / ChatGPT** через [агрегатор](https://cheap-intelligence.vercel.app/watch/tools-map) — сложные задачи (без секретов).

=== "🌍 global-эталоны"

    - **GitHub Copilot** (+ agent), **Cursor** (Composer, multi-file), **Claude Code**, **OpenAI Codex**, **Amazon Q**
    - **Схема, которая устоялась в компаниях к 2026 году:** Copilot раскатывают на всех как базовый
      слой автодополнения, а агента вроде Claude Code берут снизу сильные инженеры под сложную
      агентную работу. Это не «выбрать один инструмент», а два слоя с разными задачами.
      (security/миграции), **Gemini Code Assist**. Из РФ — VPN/зарубежная карта.

## Один рабочий плейбук

!!! example "Новая фича через агента — с контролем"
    1. Опишите задачу и критерии приёмки агенту (Cursor/Copilot agent).
    2. Агент: план → код → тесты → запуск → правка по ошибкам.
    3. **Проверьте человеком:** ревью диффа, краевые случаи, безопасность; прогоните свои тесты.
    4. Сложный баг — сначала диагностируйте сами, потом просите гипотезы.
    5. Выход: фича быстрее, но в прод — только через ваше ревью.

## Где НЕ применять

!!! danger "Красные флаги"
    - **Код в прод без ревью** — ИИ генерит правдоподобные баги и уязвимости.
    - **Секреты, ключи, приватный код** — не в сторонние сервисы; для приватного — локальные модели.
    - **Архитектурные решения** — ИИ предлагает варианты, отвечает человек.
    - **Лицензии сгенерированного кода** — проверять происхождение/совместимость.

## Промпт-паттерны: хорошо / плохо

| Плохо | Хорошо |
|---|---|
| «Напиши функцию X» | «Каркас функции X + где она сломается под нагрузкой» |
| «Почини баг» | «2 вероятные причины бага и как проверить каждую» |
| «Оптимизируй» | «Где узкое место и какие компромиссы у вариантов?» |

## Куда переносить вес
Время от 🟢-рутины — в 🔴: архитектура, безопасность, «босс агентов» (оркестрация), ответственность за прод (гл. 5).

### Было / стало / осталось за человеком
| Было (барьер до ИИ) | Стало доступно быстро | Осталось за человеком |
|---|---|---|
| Каждую фичу, тест и миграцию писал руками | Черновик кода, тестов, миграций — за минуты | Архитектура и границы системы |
| Локализация бага — часы по логам | Гипотеза по логам и фикс — быстро | Ревью в прод, безопасность, ответственность за инцидент |
| Порог «полутехнических» задач высок | Плагины, выгрузки, интеграции — по силам | Что вообще стоит строить и зачем (outcome) |

### Лестница уровней в этой роли

Пять уровней из главы 5 — на языке этой профессии. Отметьте, где вы стоите в главных задачах недели.

| Уровень | Как это выглядит здесь |
|---|---|
| **1. Пользователь ИИ** | Генерирую код и тесты с ассистентом |
| **2. Валидатор** | Ревьюю то, что выдал агент: безопасность, краевые случаи, чужие зависимости |
| **3. Оркестратор** | Веду несколько агентов на multi-file правках — работаю боссом агентов |
| **4. Владелец результата** | Отвечаю за работающий прод — не за строки кода |
| **5. Создатель системы** | Собрал систему из тестов, журналов и откатов, которая держит качество без моего присмотра |

**Где обычно застревают.** Junior-задачи уходят первыми, поэтому уровень 1 перестаёт быть позицией. Дорожают архитектура, безопасность и ответственность за прод.
