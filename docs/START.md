# С нуля: первые шаги с ИИ

> Для тех, кто ни разу толком не открывал нейросеть. Спокойно, по шагам, без жаргона.
> **Проверено: 2026-06.** Доступность сервисов из РФ меняется — смотрите дату.

Три коротких шага, чтобы начать сегодня:

1. **[Какую нейросеть открыть из России](https://cheap-intelligence.vercel.app/start/01-vybrat-neyroset)** — что работает без VPN и с оплатой РФ-картой.
2. **[Первые 15 минут](https://cheap-intelligence.vercel.app/start/02-pervye-15-minut)** — простые проверки из вступления книги: не верьте — проверьте.
3. **[Безопасность](https://cheap-intelligence.vercel.app/start/03-bezopasnost)** — что нельзя отправлять в чат и как не попасться на уверенную ошибку.
4. **[Авторский стек](https://cheap-intelligence.vercel.app/start/04-avtorskiy-stek)** — чем пользуется сам автор (по желанию; для упражнений не обязательно).

Дальше — выбирайте свою дверь: [как ИИ меняет мою работу](../applications/_index.md) или
[пройти книгу по шагам](../playbooks/tom1-workbook.md).
