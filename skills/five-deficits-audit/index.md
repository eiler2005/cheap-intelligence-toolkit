# Навык: аудит пяти дефицитов

> Зеро-инстал инструмент к **главе 7** («Навыки, которые дорожают»). Считает в браузере, данные
> никуда не уходят. Лицензия кода — MIT.

Когда output дешевеет, дорожают пять дефицитов: **суждение, вкус, доверие, внимание, дистрибуция**.
Инструмент помогает увидеть, какой у вас уже силён (но рынок не видит), какой провисает — и выбрать
один ход на квартал.

<a class="md-button md-button--primary" href="tool.html">Открыть инструмент →</a>

## Что он делает

- По 2–3 реальным задачам недели вы отмечаете каждый дефицит: силён / нейтрально / провисает,
  плюс метка «не оцифрован» (есть, но рынок не видит).
- Инструмент выбирает **один** дефицит, где ход даст больше всего, и предлагает конкретный шаг
  и дату проверки через квартал.
- Итог можно скопировать.

## Как пользоваться

1. Откройте инструмент, пройдите пять дефицитов по своим задачам.
2. Возьмите один ход на квартал — не три.
3. Можно отдать итог ИИ-ассистенту: «вот мой дефицит и ход — помоги уточнить и собрать proof,
   что я закрыл его». Просите варианты и слабые места.

## Дисциплина

«Сильным» считается дефицит, к которому есть пример последствий, а не самооценка. «Доверие»
подтверждается чужим поведением (подписывают не глядя), а не самоощущением. Распыление на три
дефицита = ноль.

## 📋 Версия для чата с ИИ (если без браузера)

Нет доступа к инструменту — скопируйте промпт ниже целиком и вставьте в чат с любым ИИ (Алиса,
ChatGPT, Claude и т.п.), затем опишите свои задачи.

```text
Прогони мою неделю через пять дефицитов, которые дорожают по мере того как ИИ дешевит типовую
работу: суждение, вкус, доверие, внимание, дистрибуция.

Вот 2–3 реальные задачи моей недели: [опишите задачи]

Для каждого из пяти дефицитов отметь: силён (есть пример последствий, не самооценка) / нейтрально /
провисает / «не оцифрован» (дефицит есть, но рынок/начальство его не видит и не считает).
«Доверие» подтверждается чужим поведением (подписывают не глядя, доверяют без проверки), не моим
самоощущением. Не давай мне три хода — выбери ОДИН дефицит, где ход даст больше всего за квартал, и
предложи конкретный шаг + как я проверю через три месяца, что закрыл его.
```
