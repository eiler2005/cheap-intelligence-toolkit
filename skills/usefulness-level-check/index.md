# Навык: мой уровень полезности

> Зеро-инстал инструмент к **главе 5** («Пять уровней новой полезности»). Считает в браузере,
> данные никуда не уходят. Лицензия кода — MIT.

Помогает увидеть, на каком уровне реально стоит ваша задача: исполнитель → пользователь ИИ →
валидатор → оркестратор → владелец результата → создатель системы.

<a class="md-button md-button--primary" href="tool.html">Открыть инструмент →</a>

## Что он делает

- Вы берёте одну конкретную задачу недели и отмечаете, где она стоит.
- Отвечаете на проверку против самообмана — и инструмент **не даёт завысить уровень**: если у
  задачи нет критериев «правильно», вы ещё не валидатор; если решение не работает без вас, это ещё
  не система.
- Возвращает честный уровень и конкретный **ход на +1**.

## Как пользоваться

1. Откройте инструмент, разберите 1–2 главные задачи недели.
2. Возьмите предложенный ход на +1 в работу на ближайшие недели.
3. Можно отдать результат ИИ-ассистенту: «вот моя задача и уровень — помоги собрать ход на +1,
   покажи, что проверить». Просите варианты, не готовое решение.

## Дисциплина

Уровень — про задачу, не про человека: в разных задачах он разный. Не делайте из него ярлык на себя.
Цель — поднять уровень там, где это даст больше всего пользы, а не везде сразу.

## 📋 Версия для чата с ИИ (если без браузера)

Нет доступа к инструменту — скопируйте промпт ниже целиком и вставьте в чат с любым ИИ (Алиса,
ChatGPT, Claude и т.п.), затем опишите свою задачу.

```text
Помоги мне честно определить, на каком из пяти уровней новой полезности стоит моя задача — и какой
один ход даст +1 уровень. Уровни (от низкого к высокому):
1. Исполнитель — делаю работу руками/головой без ИИ.
2. Пользователь ИИ — отдаю задачу ИИ, использую черновик как есть.
3. Валидатор — проверяю и исправляю результат ИИ по чётким критериям «правильно/неправильно».
4. Оркестратор — управляю несколькими шагами/инструментами/агентами к одному результату.
5. Владелец результата — отвечаю за outcome целиком, ИИ и люди — мои инструменты.
(Иногда добавляют 0: создатель системы — то, что работает без моего участия каждый раз.)

Вот моя задача: [опишите одну конкретную задачу из вашей недели]

Не дай мне завысить уровень: если у задачи нет чётких критериев «правильно» — это ещё не уровень
3 (валидатор); если решение не работает без моего постоянного участия — это ещё не уровень 5.
Назови мой реальный уровень и предложи один конкретный ход на +1 — не план на пять шагов, один ход.
```
