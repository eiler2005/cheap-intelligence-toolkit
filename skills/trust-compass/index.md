# Компас доверия: заполнить и сохранить

> Local-first инструмент к **Тому 3 «Доверие»**, главе 13.
> Вы заполняете два дорогих сценария, второй канал, независимую опору и один ход. Данные остаются
> в браузере и никуда не отправляются.

<a class="md-button md-button--primary" href="tool.html">Открыть Компас доверия →</a>

## Что получится

- один протокол для дома и работы;
- Markdown для заметок или обсуждения с близкими и командой;
- версия для печати;
- короткая запись в [Моём профиле](../my-profile/index.md).

Инструмент не распознаёт подделки и не решает, настоящий ли человек, голос, изображение или файл.
Он помогает назвать, **какую проверку вы заранее считаете достаточной** при высокой цене ошибки.

Без JavaScript используйте [итог одной страницей](../../playbooks/tom3-workbook.md#мой-протокол-доверия--итог-одной-страницей).
