# Навык: сборщик личного харнесса

> Зеро-инстал инструмент к **главе 6** («Человек как система»). Считает в браузере, данные никуда не
> уходят. Лицензия кода — MIT.

Харнесс — система вокруг ИИ, которая и определяет результат: не мотор-модель, а вся машина. Инструмент
оценивает **семь слоёв** вашей личной системы (Thinking · Knowledge · Tools · Proof · Trust · Outcome ·
Skills) и находит самое слабое звено — чтобы вы укрепляли его, а не оттачивали и без того сильное.

<a class="md-button md-button--primary" href="tool.html">Открыть инструмент →</a>

## Что он делает

- Вы оцениваете каждый из семи слоёв по шкале **1–3** (нет / непоследовательно / системно).
- Инструмент считает итог **/21**, рисует срез по слоям и выбирает **слабейшее звено**.
- Предлагает **один ход** под этот слой и дату проверки через квартал; итог можно скопировать.

## Как пользоваться

1. Откройте инструмент, оцените семь слоёв по своим реальным задачам недели.
2. Возьмите один слой на квартал — цепь прочна по слабейшему звену, распыление не работает.
3. Итог можно отдать ИИ-ассистенту: «вот срез моего харнесса и слабое звено — помоги собрать
   конкретный план на слой и proof, что я его закрыл». Просите варианты и слабые места.

## Дисциплина

Оценка «3» — это «работает системно каждый раз», а не «иногда получается». Слой Trust подтверждается
чужим поведением (доверяют без перепроверки), а не самоощущением. Один слой на квартал, не семь сразу.

## 📋 Версия для чата с ИИ (если без браузера)

Нет доступа к инструменту — скопируйте промпт ниже целиком и вставьте в чат с любым ИИ (Алиса,
ChatGPT, Claude и т.п.), затем опишите свои задачи.

```text
Оцени мой личный «харнесс» — систему вокруг ИИ, которая определяет мой результат. Семь слоёв:
1) Thinking — думаю вместе с ИИ, сохраняя навык; 2) Knowledge — личная база знаний;
3) Tools — инструменты с понятной ролью; 4) Proof — публичные артефакты работы;
5) Trust — репутация за качество и проверенность; 6) Outcome — связь работы с реальным результатом;
7) Skills — повторяемые способы работы (шаблоны/skills с границами).

Вот 2–3 реальные задачи моей недели: [опишите задачи]

Для каждого слоя поставь 1 (нет/случайно) / 2 (есть, но непоследовательно) / 3 (работает системно).
Посчитай итог из 21. Найди слабейшее звено (не самое сильное) и дай ОДИН конкретный ход на квартал
именно под него + как я проверю через три месяца, что закрыл. Не давай семь советов сразу.
```
