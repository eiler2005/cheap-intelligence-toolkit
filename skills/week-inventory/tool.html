# Задача (конкретно) Часов Корзина Рычаг

Корзина: 🟢 «ИИ сам» · 🟡 «человек + ИИ» · 🔴 «только человек». Рычаг (гл. 2): ① новые деньги · ② экономия · ③ внимание/доверие · «—» ни один (это занятость, не ценность).
