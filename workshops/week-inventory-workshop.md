# Воркшоп: неделя команды по корзинам — 90 минут

> Командная версия листа [«Разбор недели»](../playbooks/week-inventory.md) (Том 1, глава 3) —
> для команд и HR/L&D. Участники: команда 4–10 человек. Подходит как первый контакт команды с
> темой ИИ вообще: без инструментов, без внедрений — только честная карта работы.

**Результат сессии:** карта задач команды по корзинам 🟢/🟡/🔴, три задачи-кандидата на перенос
веса и договорённость, что никто не «оптимизируется» по итогам карты — это диагностика, не аттестация.

## Зачем это команде (и HR)

Разговор «как ИИ повлияет на нас» в командах либо не происходит, либо происходит в курилке — в
жанре страхов. Этот воркшоп переводит его в жанр инвентаря: не «заменят ли нас», а «какие из
наших задач типовые, какие требуют человека, и куда переносить вес». После него у команды общий
язык (корзины) и общая карта.

## Подготовка

- Каждый участник за день до сессии выписывает **10–15 своих задач прошлой недели** — по
  календарю и переписке, как было, а не как должно быть. Это единственная подготовка.
- Ведущий читает [лист-первоисточник](../playbooks/week-inventory.md) и определение корзин.

## Агенда 90 минут

| Время | Блок | Как |
|---|---|---|
| 0–10 | Рамка и правило безопасности | Вслух: «Карта — про задачи, не про людей. По итогам никого не „оптимизируют" — мы ищем, куда переносить вес». Без этого правила честных ответов не будет. |
| 10–20 | Корзины | Ведущий объясняет 🟢 «ИИ сам» / 🟡 «человек + ИИ» / 🔴 «только человек» на 2–3 задачах из своего списка — включая одну неудобную для себя. |
| 20–40 | Индивидуальная разметка | Молча: каждый раскладывает свои задачи по корзинам + помечает задачи-«занятость» (без рычага: не деньги, не экономия, не внимание). |
| 40–60 | Общая карта | По кругу: каждый называет свою долю 🟢 и одну 🔴-задачу. Ведущий собирает повторы: задачи, которые в 🟢 у всех, — кандидаты на общий шаблон/агента; задачи, которые у одних 🟢, у других 🔴, — самые интересные, их обсуждаем. |
| 60–75 | Три кандидата | Команда выбирает: 1 задачу «в 🟢 целиком» (шаблон/скилл), 1 задачу «🟡 с проверкой» (черновик — ИИ, приёмка — человек, по какому чек-листу), 1 🔴-задачу, в которую переносим освободившийся вес. |
| 75–90 | Личный ход | Каждый записывает один свой ход на 2 недели (не команде — себе). Желающие озвучивают. Фото карты. |

## После сессии

- Через 2 недели — 15-минутный чек-ин: у кого ход случился, у кого нет и почему.
- Желающим — индивидуальное продолжение: [Рабочая тетрадь Тома 1](../playbooks/tom1-workbook.md)
  (это её шаг 2) или свой разбор в [браузерном инструменте](../skills/week-inventory/index.md).
- Команде, которая дозрела до агента, — [воркшоп по скорингу](process-scoring-workshop.md).

## Грабли

- **Задачи «как должно быть» вместо «как было».** Лечится календарём: только то, что реально
  занимало время на прошлой неделе.
- **Соревнование «у кого меньше 🟢».** Большая доля 🟢 — не приговор, а ресурс: это время, которое
  можно перенести в 🔴. Проговорить прямо.
- **HR ждёт «карту на сокращение».** Правило безопасности из первого блока — обещание, которое
  нельзя нарушать: одна «оптимизация» по итогам — и следующей честной карты не будет никогда.
