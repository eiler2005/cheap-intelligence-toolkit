# Воркшопы для команды

> Готовые сценарии рабочих сессий по инструментам Практикума: агенда, роли, тайминг, артефакт на
> выходе. Для руководителей, HR/L&D и всех, кто хочет пройти инструмент не в одиночку.

Инструменты Практикума работают и в одиночку, но у командного прохода есть два преимущества:
решения принимаются при всех (их сложнее «забыть») и страхи проговариваются вслух (их сложнее
раздувать). Каждый сценарий рассчитан на **90 минут**, не требует подготовки участников и
заканчивается заполненным артефактом, а не «обменом мнениями».

| Воркшоп | Для кого | Артефакт на выходе |
|---|---|---|
| [Где ИИ окупится: скоринг процессов](process-scoring-workshop.md) | управленческая команда, владелец МСП с ключевыми людьми | таблица скоринга + один процесс первого круга + список «почему нет» |
| [Первый агент команды: контракт](agent-contract-workshop.md) | команда функции (поддержка, продажи, бэк-офис) | заполненный контракт агента с границами, порогом-стопом и владельцем |
| [Неделя команды по корзинам](week-inventory-workshop.md) | любая команда 4–10 человек; HR/L&D | карта задач команды 🟢/🟡/🔴 + три кандидата на перенос веса |

**Общие правила фасилитации** (для всех трёх):

1. **Таймер видят все.** 90 минут — жёсткие; лучше недообсудить, чем не дойти до артефакта.
2. **Сначала пишут молча, потом говорят.** Каждый блок начинается с 3–5 минут индивидуального
   заполнения — иначе говорит самый громкий, а не самый точный.
3. **«Нет» — тоже результат.** Процессы и задачи, которым ИИ не нужен, записываются с причиной,
   а не отбрасываются.
4. **Артефакт фотографируется до выхода из комнаты** и получает владельца с датой следующего шага.
