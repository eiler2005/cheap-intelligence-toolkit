# Воркшоп: где ИИ окупится — скоринг процессов за 90 минут

> Командная версия листа [«Скоринг процессов»](../playbooks/process-scoring.md) (Том 2, глава 11).
> Участники: 3–8 человек, знающих операции с разных сторон. Ведущий — любой, не обязательно
> руководитель.

**Результат сессии:** таблица скоринга по 10–20 процессам, один процесс первого круга, список
«почему нет» — и ни одного «давайте внедрим ИИ» без адреса.

## Подготовка (ведущему, 30 минут до сессии)

- Распечатать/расшарить таблицу скоринга (шаблон в [листе](../playbooks/process-scoring.md)) и
  пять вопросов на видное место.
- Попросить каждого участника принести список «мои повторяющиеся процессы» — не обязательный,
  но ускоряет старт.
- Прочитать два примера: [IKEA](../playbooks/ikea-compass-example.md) и
  [Klarna](../playbooks/klarna-compass-example.md) — второй пригодится, когда кто-то предложит
  «заменить всех».

## Агенда 90 минут

| Время | Блок | Как |
|---|---|---|
| 0–10 | Рамка | Ведущий: «Мы не выбираем ИИ-инструмент. Мы ищем процессы, где агент окупится, — и честно записываем, где нет». Пять вопросов вслух. |
| 10–25 | Выгрузка процессов | Молча, каждый пишет свои повторяющиеся процессы (не отделы! «отвечаем на заявки», а не «продажи»). Затем по кругу — на общую доску, дубли склеиваются. Цель: 10–20 штук. |
| 25–50 | Скоринг | По каждому процессу — пять вопросов, ответ «да» только при живом примере («да, проверяем по чек-листу — вот он»). Спорное «да» = «нет». Сумма записывается сразу. |
| 50–60 | Шестой фильтр | Для процессов с 4–5 «да»: «кто может написать инструкцию для этого процесса — сегодня?» Нет человека — процесс уходит во второй круг. |
| 60–75 | «Почему нет» | Процессы с ≤2 «да» получают причину и условие («станет „да", когда…»). Это защита от будущих продавцов внедрений. |
| 75–90 | Решение | Один процесс первого круга (при равенстве — где ошибка дешевле). Владелец. Следующий гейт по [листу гейтов](../playbooks/change-gates.md) и дата. Фото артефакта. |

## Грабли, о которых стоит знать заранее

- **«Внедрим везде».** Ответ — Klarna: даже при работающем агенте перепрыгнутый гейт стоит дороже
  экономии. Начинаем с одного процесса.
- **«У нас всё уникальное».** Просите пример за прошлую неделю. Уникальное, случившееся 40 раз, —
  это повторяющийся процесс.
- **Скоринг превращается в защиту территорий.** Правило: оцениваем процесс, а не людей; блок
  «люди» будет отдельным ходом ([обучение в потоке](../playbooks/training-in-the-loop.md)).
