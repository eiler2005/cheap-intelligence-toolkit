# Том 3 по главам: где лежит практика каждой главы

> Указатель к книге «Когда интеллект стал дешёвым. Том 3: Доверие».
> Практикум Тома 3 собран не по странице на главу, а тремя «домами» — защита, проверяемый след,
> компас. Этот лист переводит с языка книги на язык сайта: дочитали главу — нашли её материал.

Общий маршрут тома — [Рабочая тетрадь Тома 3](tom3-workbook.md). Если времени мало, начните с
«Минимального пакета доверия» в ней: пять листов на один вечер.
