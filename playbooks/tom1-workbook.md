# Рабочая тетрадь Тома 1 «Человек»

> Сквозной маршрут Практикума к Тому 1 книги «Когда интеллект стал дешёвым».
> Это «оглавление-маршрут»: проведёт вас от рычагов ценности и разбора недели до личного плана на
> 90 дней, по одному шагу на главу. Отдельные листы остаются для точечного входа — а здесь они связаны
> в путь.
>
> **Ось этого трека — ваша профессия.** Том 1 организован вокруг профессий: специалист смотрит на свою
> работу. Бизнес-трек — вокруг функций компании — во [второй тетради](tom2-workbook.md).

Заполняйте по мере чтения книги. На каждом шаге — короткий перенос вывода сюда и ссылка на полный
рабочий лист. В конце у вас на руках заполненный план на 90 дней, собранный не из воздуха, а из
вашего же диагноза. Это ещё и **портфельный артефакт специалиста**: одна страница, где видно, какую
ценность вы создаёте, что делегируете ИИ, что оставляете за собой и какой следующий уровень берёте.

Две двери в Практикум: эта тетрадь (идти по книге) — и [выбор профессии](https://cheap-intelligence.vercel.app/applications/_index) (если хотите
сразу «как ИИ меняет мою работу»). Можно совмещать.

## Мой итог одной страницей

Соберите ответы шагов 1–10 в одну таблицу — это ваш профиль, который можно распечатать, показать
руководителю, приложить к разговору о роли или отдать своему ИИ-ассистенту. Хороший итог не выглядит
как «я умею пользоваться нейросетью»; он показывает, какую работу вы теперь делаете на уровень выше.

| Шаг | Мой вывод |
|---|---|
| 1. Рычаг ценности | `____` |
| 2. Неделя по корзинам | 🟢 `____%` · 🟡 `____%` · 🔴 `____%` |
| 3. Моя лестница | `____` |
| 4. Уровень полезности и ход +1 | сейчас `____` → следующий ход `____` |
| 5. Слабый слой личной системы | `____` |
| 6. Один дорожающий навык | `____` |
| 7. Режим работы с ИИ | `____` |
| 8. Интегральный диагноз профессии | `____` |
| 9. Я отвечаю не за X, а за Y | `____` |
| 10. План на 90 дней | задача `____` · новое правило `____` · метрика `____` |
| 1. Главный рычаг моей работы | `____________` |
| 2. Доля 🟢 в неделе / главная 🔴-задача | `____ %` / `____________` |
| 3. Место на лестнице + зацеп | `____________` |
| 4. Уровень полезности + кандидат на +1 | `____` / `____________` |
| 5. Слабый слой личной системы | `____________` |
| 6. Навык, который тренирую | `____________` |
| 7. Режим работы с ИИ + правило-страховка | `____________` |
| 8. Слабое место / несгораемая ценность | `____________` |
| 9. Я отвечаю за | `____________` |
| 10. Одна задача на 90 дней + проверяемое изменение | `____________` |

Хотите взгляд со стороны — скопируйте заполненную таблицу в чат с ИИ вместе с промптом:

```text
Вот мой профиль по рабочей тетради Тома 1 книги «Когда интеллект стал дешёвым» (10 строк:
рычаг, корзины недели, лестница, уровень полезности, слабый слой системы, навык, режим работы
с ИИ, диагноз, «я отвечаю за», план на 90 дней). Проверь его на честность: где выводы противоречат
друг другу, где я себе льщу, какой из шагов самый слабый. Не переписывай план — задай мне три
вопроса, после которых я сам захочу его уточнить.
[вставьте таблицу]
```
