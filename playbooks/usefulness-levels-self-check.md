# Рабочий лист: мой уровень полезности

> Практикум к главе 5 «Пять уровней новой полезности».
> Время: 30–40 минут.
> Источник данных — последняя рабочая неделя, а не резюме и не должностная инструкция.

🧮 **Быстрее:** [интерактивная версия в браузере](https://cheap-intelligence.vercel.app/skills/usefulness-level-check/) — определяет
уровень задачи и не даёт его завысить (без установки, данные не уходят).

Цель: понять уровень одной конкретной задачи. Не «какой я человек», а «за что мне платят в этой
связке работы, ИИ и результата».

## 1. Выберите одну задачу

Возьмите результат, который вы делали с ИИ за последнюю неделю.

Пишите конкретно:

- подготовил черновик презентации;
- разобрал договор;
- собрал отчёт;
- ответил клиенту;
- сделал анализ таблицы;
- подготовил решение для руководителя.

Не пишите слишком широко: «работал над проектом», «занимался клиентами», «делал аналитику».

**Моя задача:**
`____________________________________________________________`

## 2. Четыре вопроса

| Вопрос | Ваш ответ |
|---|---|
| Какой outcome должен был измениться? | |
| Кто принял решение на основе результата? | |
| Какая ошибка была бы неприемлемой? | |
| Что в следующий раз улучшит мой контекст, а не возможности модели? | |

Если на все четыре вопроса ответа нет, задача, скорее всего, стоит на уровне 0–1: вы ускорили output,
но ещё не владеете проверкой, процессом или результатом.

## 3. Определите уровень задачи

| Уровень | Быстрый признак | Это про вашу задачу? |
|---|---|---|
| **0. Исполнитель инструкции** | получил постановку, сдал результат | |
| **1. Пользователь ИИ** | сделал быстрее с моделью | |
| **2. Валидатор** | проверил критерии, качество и риск | |
| **3. Оркестратор** | собрал процесс из людей, агента, данных и инструментов | |
| **4. Владелец результата** | отвечал за метрику, клиента, деньги или риск | |
| **5. Создатель системы** | упаковал решение так, что оно работает без вас | |

**Текущий уровень этой задачи:**
`____`

**Почему:**
`____________________________________________________________`

## Проверка против самообмана

- Если вы просто стали делать больше однотипного output, это не подъём выше первого уровня.
- Если модель делает всё, а вы только пересылаете ответ, это нулевая отметка с моторчиком.
- Если у вас нет критериев «правильно», вы ещё не валидатор.
- Если никто не понимает, кто отвечает за outcome, вы ещё не владелец результата.
- Если решение не воспроизводится без вас, это ещё не система.
