# Гид: чему учить, когда ответы дешевеют

> Практикум к Тому 2, главе 7 «Дети: чему учить и куда вести».
> Время: 10-15 минут. Это не список профессий будущего, а карта способностей, которые стоит
> растить дома годами.

Главный вопрос главы не «кем будет ребёнок», а «что в нём станет сильнее, пока машины дешевят
готовые ответы». Используйте этот лист как семейный фильтр: что тренировать самим, где ИИ может быть
тренажёром, а где он уже забирает нагрузку.

---

## 1. Пять дорогих способностей

| Что дорожает | Что это значит дома | Как использовать ИИ без потери навыка |
|---|---|---|
| **Вопросы** | Ребёнок замечает, чего не хватает, что не сходится, о чём забыли спросить. | Просите ИИ не отвечать сразу, а задавать уточняющие вопросы к плану ребёнка. |
| **Вкус и суждение** | Ребёнок отличает сильное от слабого и объясняет почему. | Сравнивайте два варианта: свой и машинный. Пусть ребёнок выбирает и защищает выбор. |
| **Агентность** | Ребёнок ставит цель, начинает без разрешения, меняет план после провала. | ИИ помогает разложить проект на шаги, но цель, выбор и ответственность остаются у ребёнка. |
| **Живая связь** | Ребёнок слышит другого человека, выдерживает несогласие, просит о помощи. | ИИ можно использовать для репетиции разговора, но не вместо самого разговора. |
| **Учиться учиться** | Ребёнок проходит цикл: разобрался, применил, ошибся, исправил, зашёл снова. | ИИ даёт упражнения, подсказки и проверочные вопросы, но не закрывает весь цикл за ребёнка. |

Если занятие не растит ни одну из этих способностей, проверьте: это правда отдых, или просто ещё один
способ быстрее сдать готовое?

## 2. Что можно спокойно отдавать ИИ

ИИ можно отдавать то, что не является главным тренажёром навыка:

| Можно отдать | Нельзя отдавать целиком |
|---|---|
| поиск вариантов, примеров, источников | формулировку собственного вопроса |
| объяснение темы разными способами | первую попытку понять самому |
| проверку черновика на ошибки | выбор, что считать хорошим результатом |
| генерацию тренировочных задач | саму тренировку |
| планирование шагов проекта | цель, ставку и ответственность |

Правило простое: если после ИИ ребёнок стал сильнее думать, выбирать или проверять, режим годится.
Если он просто быстрее принёс готовое, тренировка обойдена.

## 3. Семейный мини-аудит

Выберите одно занятие ребёнка: школа, кружок, спорт, проект, игра, семейное дело.

| Вопрос | Ответ |
|---|---|
| Где здесь ребёнок задаёт свои вопросы? | |
| Где он сравнивает качество и объясняет выбор? | |
| Где у него есть настоящий выбор и последствия? | |
| Где есть живой человек, у которого можно перенять мастерство? | |
| Где он проходит полный цикл обучения, а не только получает подсказку? | |

Если пустых строк больше двух, не ищите новый «модный» кружок сразу. Сначала добавьте одну ступеньку:
реальный проект, живого наставника, публичный след результата или правило «подсказка, а не ответ».

## 4. Один ход на неделю

Выберите только один:

| Если просел навык | Ход на неделю |
|---|---|
| Вопросы | За ужином три раза спросить: «Что тебя сегодня удивило?» и не отвечать вместо ребёнка. |
| Вкус и суждение | Вместе разобрать один фильм, текст, вещь, код или блюдо по схеме: что сильно, что слабо, как улучшить. |
| Агентность | Дать ребёнку маленький проект со ставкой: результат увидит кто-то вне семьи. |
| Живая связь | Запланировать один разговор без экрана и без оценки, где взрослый сначала слушает. |
| Учиться учиться | Попросить ИИ составить тренировку, но финальную проверку сделать без ИИ. |

Через неделю спросите не «получилось ли идеально», а «где ребёнок делал сам».
