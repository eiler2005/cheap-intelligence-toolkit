# Интегральная карта аудита профессии

> Практикум к главе 9 «Личный аудит профессии». Время: 30–45 минут.
> Источник данных — ваша реальная рабочая неделя, не резюме и не должностная инструкция.

Глава 9 не вводит новый инструмент — она **сводит в одну картину** то, что вы уже разбирали по
отдельности: уровень полезности (гл. 5), личную систему-harness (гл. 6), режим работы с ИИ (гл. 8) и
карту от задачи к результату (гл. 6). Этот лист — агрегатор. Если соседние воркшиты вы уже заполняли,
просто перенесите их выходы сюда и обновите.

Цель — получить на одном листе свой диагноз: что дешевеет, где слабое место, что несгораемое, куда
один шаг роста. Без баллов и «индекса замещаемости» — это карта, а не тест личности.

---

## Блок A. Карта от задачи к результату (3–4 задачи)

[task-to-outcome-map.md](task-to-outcome-map.md)).

| | | | |
| | | | |

## Блок B. Пять координат

Заполняемые поля; в скобках — откуда взять выход.

1. **Лестница** (вход / середина / верх — из гл. 4, [ladder-self-diagnosis.md](ladder-self-diagnosis.md)):
   `____________`
2. **Уровень полезности 0–5** (из гл. 5, [usefulness-levels-self-check.md](usefulness-levels-self-check.md)):
   `____`
3. **Режим работы с ИИ** (киборг / центавр / самоавтоматизатор — из гл. 8,
   [ai-mode-audit.md](ai-mode-audit.md)): `____________`
4. **Слабый слой личной системы** (мышление / знания / инструменты / proof / доверие / outcome — из
   гл. 6, [personal-harness-builder.md](personal-harness-builder.md)): `____________`
5. **Несгораемая ценность** (что в вас труднее всего быстро скопировать — опыт, вкус, доверие,
   отношения, контекст): `____________________________________________`

## Блок C. Сводка диагноза

Соберите одной фразой каждое:

- **Что дешевеет** (задачи, уходящие к машине): `____________________________________`
- **Слабый слой / координата, которую чинить первой:** `____________________________`
- **Одна несгораемая ценность, на которую опираюсь:** `____________________________`
- **Один +1** (где один шаг вверх по уровню даст больше всего): `____________________`

Это и есть ваш диагноз на одном листе. Не «программа развития на 5 страниц» — четыре строки, из
которых дальше вырастает план.
