# Personal Harness Builder

> Практикум к главе 6 «Человек как система».
> Время: 30–45 минут.
> Используйте после [Task-to-Outcome Map](task-to-outcome-map.md) — когда уже знаете, какие задачи анализируете.

Харнесс (harness) — система вокруг ИИ, которая определяет результат. Глава 6 описывает шесть слоёв личной полезности и отдельный практический слой навыков (`skills`): повторяемых способов работы, которые не нужно каждый раз объяснять ИИ заново. Этот воркшит помогает увидеть, как выглядит ваш харнесс прямо сейчас.

## Шаг 2. Срез по слоям

Оцените каждый слой вашего харнесса по шкале 1–3:

- **1** = не существует / случайный порядок
- **2** = есть, но непоследовательно
- **3** = работает системно, каждый раз

## Шаг 4. Один конкретный шаг на следующие 2 недели

Не «буду улучшать Knowledge», а конкретное действие:

Плохо: «Создам базу знаний»
Хорошо: «К пятнице создам одну папку в Notion/Obsidian, куда буду складывать выводы из рабочих встреч»

Плохо: «Стану лучше верифицировать ИИ»
Хорошо: «Для каждого отчёта, который сдаю руководителю, буду проверять три ключевых цифры вручную»

Плохо: «Сделаю себе skills»
Хорошо: «Опишу один skill для еженедельного отчёта: входные данные, шаги, проверка, где ИИ должен остановиться»
