# Аудит ученичества в команде: 3C

> Практикум к главе 4 «Лестница рушится: вход и середина».
> Основа: Matt Beane, *The Skill Code*: challenge, complexity, connection.

Цель: проверить, не разобрала ли команда лестницу, по которой должна вырасти её следующая смена.

## 1. Challenge: есть ли здоровый вызов

| Вопрос | Да / нет | Что поправить |
|---|---|---|
| Новички получают задачи чуть выше текущего уровня? |  |  |
| Есть безопасные задачи, где можно ошибиться и получить разбор? |  |  |
| ИИ помогает учиться, а не просто выдаёт готовый ответ? |  |  |

## 2. Complexity: видит ли человек целое

| Вопрос | Да / нет | Что поправить |
|---|---|---|
| Новичок понимает, зачем делается задача и кому нужен результат? |  |  |
| Он видит путь от запроса до решения, а не только свой маленький кусок? |  |  |
| После автоматизации рутины остались ручные разборы реальных кейсов? |  |  |

## 3. Connection: есть ли связь с мастером

| Вопрос | Да / нет | Что поправить |
|---|---|---|
| У новичка есть человек, который смотрит его работу и даёт правки? |  |  |
| Есть доверие: новичку дают делать, а не только наблюдать? |  |  |
| Старшие получают время и признание за выращивание людей? |  |  |

## 4. Итоговый риск

| Уровень | Признак | Что делать |
|---|---|---|
| Низкий | 3C в основном живы | Уточнить, какие задачи можно автоматизировать без потери обучения |
| Средний | одно из 3C просело | Вернуть недостающий элемент в ближайший квартал |
| Высокий | новички только смотрят или правят готовое | Назначить учебные задачи и мастеров, иначе конвейер навыка уже сломан |
