# Карта следа доверия: чтобы вас выбирали без долгих проверок

> Практикум к **Тому 3 «Доверие»** (дом «Созидание»). Время: 30–40 минут.
> Рабочий лист для специалиста и малого бизнеса. Заполняется руками — на бумаге или в заметке.

В мире, где отзыв, резюме и «эксперт в ленте» подделываются за вечер, дорожает **проверяемое
человеческое**. Выигрывает не самый громкий, а тот, кого легко подтвердить. Задача этого листа —
не «прокачать личный бренд», а **снять с людей лишнюю проверку**: сделать так, чтобы важное про вас
можно было проверить и без вас.

> **Главный тест листа — четыре вопроса.** Сигнал трудно подделать? Он накапливается со временем?
> Его можно проверить извне? При следующем решении он снова уменьшит чужие затраты на проверку?
> Значок, самоописание и три восторженных отзыва проваливают этот тест — это шум. Годы истории,
> реальные клиенты, живой свидетель, канал с прошлым проходят его намного лучше. Первый шаг можно
> сделать за вечер; капиталом он становится через повторение, внешнюю опору и последствия.

---

## Шаг 1. Три якоря: что вообще проверяют

У доверия к специалисту три опоры. Отметьте, что у вас уже есть **проверяемого** (не «я хороший», а
«это можно подтвердить без меня»):

| Якорь | Что это | Что у меня есть сейчас | Дорого подделать? (да/нет) |
|---|---|---|---|
| **Проверяемая история** | реальные работы, кейсы, даты, результат — с возможностью проверить | `__________` | |
| **Живые референсы** | конкретные люди, которые подтвердят и с которыми можно поговорить | `__________` | |
| **Подписанный канал** | площадка, где именно вы, с историей и именем, а не аноним | `__________` | |

> Пусто в строке = слабое место. Один заполненный якорь с «дорого подделать: да» весит больше, чем
> десяток громких заявлений.

Третий якорь держится не на самой площадке, а на **последствиях**: слова в подписанном канале
привязаны к вам, и за них придётся отвечать. Именно поэтому им верят больше, чем анонимному
отзыву, — не потому, что канал красивее, а потому, что у сказанного есть цена.

## Шаг 2. Четыре канала следа

След оставляется там, где вас ищут. Для каждого канала: *что уже есть · что видит посторонний без
вас · один ход на ближайший месяц.* Не нужно вести все четыре — выберите 1–2, где ваши клиенты правда бывают.

| Канал | Что уже есть | Что видно без меня | Один ход на месяц |
|---|---|---|---|
| **Соцсети / Telegram** — где вы думаете вслух | | | |
| **Выступления / конференции** — где вас видели вживую | | | |
| **Книги / публикации / статьи** — что осталось написанным | | | |
| **Сообщество** — узкий круг, где вас знают лично | | | |

> Узкий круг, где вас знают лично, часто сильнее широкого охвата: там доверие глубже, а подделать
> репутацию среди реальных людей почти невозможно. Это ваш «тёмный лес» — см. [Компас доверия](trust-compass.md).

### Что из этого читает машина

Часть тех, кто проверяет вас, — уже программы: ассистент, к которому клиент обратился вместо
поисковика. У машины нет интуиции и презумпции добросовестности, она не додумает за вас.

| Что оставляет след для человека | Что из этого забирает машина |
|---|---|
| Пост, где вы думаете вслух | специализация, если она названа одинаково везде |
| Выступление, где вас видели | имя, тема, дата, площадка — если они выписаны текстом |
| Публикация или кейс | цифра с единицей измерения, дата, ссылка на первоисточник |
| Разговор в сообществе | ничего: закрытый круг машине не виден |

Вывод не «пишите для роботов». Вывод проще: **то, что важно для решения, должно быть выражено
явно** — имя ответственного вместо «команды», дата вместо «недавно», первоисточник вместо «по
данным исследований». Живой контекст — [сколько в сети машин](https://cheap-intelligence.vercel.app/watch/machine-web).

## Шаг 3. Ритм «показывай работу»

Капитал подлинности не заявляется — он **остаётся как побочный продукт настоящей работы**. Не пост о себе,
а артефакт: разбор кейса, метод, «как я думал», честный разбор ошибки. Один такой артефакт в неделю
или в месяц — и через год у вас след, который не подделать.

- Мой формат «показать работу»: `__________________`
- Куда выкладываю (1 канал, который контролирую): `__________________`
- Как часто (реалистично): `__________________`

Правило: **процесс убедительнее глянца.** «Как получилось» и «где ошибся» вызывают больше доверия,
чем безупречная витрина.

## Шаг 4. Подписанный канал и происхождение

Один канал, где точно вы, — сильный якорь. Плюс: важные материалы можно **подписывать происхождением**,
чтобы их не выдали за чужие (и наоборот — чтобы вашим именем не подписали фейк).

- Мой «официальный» канал, куда я веду всех: `__________________`
- Где я предупреждаю клиентов, что **пишу только отсюда** (защита от самозванцев): `__________________`
- Подпись происхождения контента ([Content Credentials / C2PA](https://contentauthenticity.org/)) —
  по желанию, для фото/видео/материалов, которые могут выдать за чужие. *Проверено: 2026-07;
  поддержка растёт (камеры, Adobe), но метка доходит до зрителя частично — это дополнение, не
  гарантия.* Статусы и пределы — в [регуляторном трекере](https://cheap-intelligence.vercel.app/watch/trust-regulation).

### Личный провенанс за один вечер

Шесть настроек, после которых ваше авторство можно подтвердить без вас:

- [ ] **Оригиналы там, где их найду:** исходники фото, версии текстов, записи выступлений лежат в
  одном месте и не удаляются после публикации.
- [ ] **У важного есть дата, которую можно показать:** публикация в своём канале, экспорт с датой
  или письмо самому себе с вложением.
- [ ] **Один канал назначен официальным**, и об этом сказано там, где меня чаще всего находят.
- [ ] **Написано, чего я никогда не делаю** — не пишу первым про деньги, не прошу переводы, не
  раздаю доступы в мессенджере. Так фейк от вашего имени опознаётся без экспертизы.
- [ ] **Подпись происхождения включена** для тех материалов, которые реально могут выдать за чужие.
- [ ] **Знаю, куда идти, если моим именем подписали чужое** — площадка, канал жалобы, срок.
  Актуальные адреса — в [регуляторном трекере](https://cheap-intelligence.vercel.app/watch/trust-regulation).

> Провенанс — не про паранойю и не про технологию. Это про то, чтобы человеку, который
> засомневался, было **дёшево** убедиться, что материал ваш.

## Шаг 5. Вас видит ИИ-поиск — и что он о вас говорит

Всё чаще клиент спрашивает не Google, а нейросеть: «кого выбрать». Если вас нет в ответе — вас нет.
Если есть, но с плохой тональностью — теряете ещё до сайта. Полный замер — в отдельном наборе:
[видимость в ИИ-поиске](geo-ai-search-kit.md). Короткая проверка «структуры, которую цитирует ИИ»:

- [ ] позиция/специализация постоянна во времени (не «сегодня одно, завтра другое»);
- [ ] есть ясный метод/подход, который можно описать;
- [ ] авторство именное (видно, кто автор), а не аноним;
- [ ] есть постоянный адрес (канал/страница), который не переезжает;
- [ ] есть история точных, подтвердившихся работ.

Чем больше галочек — тем охотнее и человек, и ИИ вас порекомендуют.

## Итог: один ход

Из всего листа выберите **самое дешёвое для вас и самое дорогое для клиента** место, где сейчас пусто:

- Мой самый слабый якорь: `__________`
- Один ход на этот месяц, который сделает его проверяемым: `__________________`

> Проверьте ход четырьмя вопросами: его трудно подделать, он будет накапливаться, его проверят без
> вас, и он упростит не одну, а будущие проверки? Если да — вы наращиваете капитал подлинности.
> Если ход только быстро улучшает витрину, это косметика, а не след.
