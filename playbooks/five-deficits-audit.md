# Аудит пяти дефицитов

> Практикум к главе 7 «Навыки, которые дорожают». Время: 25–30 минут.
> Источник данных — последняя рабочая неделя, не резюме.

🧮 **Быстрее:** [интерактивная версия в браузере](https://cheap-intelligence.vercel.app/skills/five-deficits-audit/) — выбирает один
дефицит на квартал и предлагает ход (без установки, данные не уходят).

Когда output дешевеет, дорожают пять дефицитов: **суждение, вкус, доверие, внимание, дистрибуция**.
Подлинность — не шестой пункт, а свойство всех пяти: ценно, когда видно, что за этим стоит человек.
Этот лист — не «список навыков будущего», а диагностика: какой дефицит у вас уже есть (и рынок его
не видит), какой провисает.

## Шаг 2. Пять вопросов на задачу

Для каждой задачи ответьте по пяти дефицитам:

| Дефицит | Вопрос |
|---|---|
| **Суждение** | Какие решения «по ситуации» здесь принимаю я — и что будет, если их примет модель? |
| **Вкус** | Из скольких вариантов я выбираю и по какому эталону «хорошо»? |
| **Доверие** | Мою работу здесь перепроверяют — или подписывают не глядя? |
| **Внимание** | Дошёл ли результат до человека, который принимает решение? |
| **Дистрибуция** | Узнает ли кто-то за пределами задачи, что это сделал я? |

  `____________________________________________________________`

## Проверка против самообмана

- «Сильным» считается дефицит, к которому есть пример последствий, а не самооценка.
- «Доверие» подтверждается чужим поведением (подписывают не глядя), а не самоощущением.
- Один ход — не три. Распыление = ноль.
