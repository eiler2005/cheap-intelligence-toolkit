# Task-to-Outcome Map

> Практикум к главе 6 «Человек как система».
> Время: 40–60 минут.
> Источник данных — реальные задачи последней рабочей недели, не должностная инструкция.

Цель: увидеть, где ваше время уходит на дешевеющий output, а где — на то, что дорожает.
Это точка входа в строительство личного харнесса.

---

## Шаг 1. Выберите три задачи

Возьмите три задачи из прошлой рабочей недели. Не самые приятные и не самые сложные — самые
**характерные**: те, которые повторяются.

Пишите конкретно:

- «писал ежемесячный отчёт по портфелю»
- «готовил предложение для клиента X»
- «разбирал договор с подрядчиком»
- «делал презентацию для совета директоров»
- «отвечал на запросы в поддержке»

Не пишите широко: «работал над проектом», «занимался клиентами».

**Задача 1:** `______________________________________________`

**Задача 2:** `______________________________________________`

**Задача 3:** `______________________________________________`

## Шаг 2. Семь вопросов для каждой задачи

Заполните таблицу для каждой из трёх задач. Можно начать с одной, это займёт 15 минут.

### Задача 1: `_____________`

| # | Вопрос | Ваш ответ |
|---|---|---|
| 1 | **Что я делаю?** Конкретно, пошагово — что вы физически делаете при выполнении этой задачи | |
| 2 | **Зачем это нужно?** Что должно измениться у заказчика задачи (руководитель, клиент, коллега) | |
| 3 | **Что может ИИ?** Что из п.1 ИИ уже делает или мог бы делать быстрее / дешевле | |

| 7 | **Куда подняться?** На какую роль/уровень перейти по этой задаче, если освободить время из п.6 | |

## Шаг 3. Прочитайте карту целиком

Посмотрите на три заполненных блока вместе. Ответьте на три вопроса:

**Сколько времени (в % от недели) уходит на задачи из п.3 («может ИИ»)?**

`_____ %`

Если больше 50% — это норма на 2025–2026. Это не провал. Это карта, откуда начинать.

**Где ваша верификационная точка?** Из п.4 всех трёх задач — какая ошибка ИИ обойдётся дороже всего?

`______________________________________________`

## Пример: аналитик в страховой компании (из главы 6)

Задача: «Ежемесячный отчёт об убыточности портфеля».

| # | Вопрос | Ответ |
|---|---|---|
| 1 | Что делаю? | Собираю данные из трёх систем, строю сводные таблицы, пишу объяснения к цифрам |
| 2 | Зачем? | Руководство принимает решения по тарифам и сегментам |
| 3 | Что может ИИ? | Собрать по шаблону, написать объяснения к стандартным паттернам, оформить структуру |
| 4 | Где нужен человек? | Учесть регуляторный контекст прошлой недели, отсеять артефакт от тренда, взять ответственность за рекомендацию |
| 5 | Как измерить? | Принимает ли руководство решения на основе отчёта, насколько точны прогнозы |
| 6 | Что перестать делать? | Вручную пересобирать данные, переформатировать таблицы, писать шаблонные объяснения |
| 7 | Куда подняться? | От «составитель отчёта» к «аналитик, который формулирует, какой вопрос сейчас важен» |

**Вывод из примера:** 75% времени уходило на п.1 (сбор данных) и п.3 (шаблонные объяснения).
Настоящая ценность — в п.4 и п.5. После автоматизации п.6 открылось время именно на них.
