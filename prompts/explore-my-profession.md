# Промпты: исследуйте свою профессию с ИИ

> Не нашли свою роль в [каталоге](https://cheap-intelligence.vercel.app/applications/_index) или хотите глубже? Эти готовые промпты
> помогут вам **самим** разложить свою работу с помощью ИИ — по логике книги. Копируйте, подставляйте
> своё, проверяйте ответы. **Дата: 2026-06.**
>
> Принцип (гл. 8): просите варианты, разбор и слабые места — не готовый ответ. ИИ расширяет ваш
> выбор; решаете вы. И обезличивайте: уберите имена и цифры, оставьте суть.
>
> Нужен общий метод и шаблоны под любую задачу (не только профессию) —
> [Промпты: метод + проверка](index.md).

Откройте любую нейросеть из [списка](https://cheap-intelligence.vercel.app/start/01-vybrat-neyroset) и идите по шагам. Или отдайте всё
сразу навыку [optimize-my-work](../skills/optimize-my-work/SKILL.md), если работаете в среде с агентами.

---

## 1. Разложить профессию на задачи
```
Я работаю как [профессия]. Вот мои типичные задачи за неделю: [перечислите 7–10].
Разложи их на три корзины:
🟢 «ИИ может сам» (чёткий вход, проверяемый выход),
🟡 «человек + ИИ» (машина — черновик, человек — контекст и проверка),
🔴 «только человек» (суждение, ответственность, доверие, живой контакт).
По каждой корзине — одна строка, что происходит с ценностью этой работы.
```

## 2. Найти, что дешевеет и что дорожает
```
Для профессии [роль] в эпоху ИИ: что в моей работе дешевеет (становится гигиеной) и что дорожает?
Свяжи с тем, за что реально платят: результат, проверка, доверие, отношения. Без хайпа, по делу.
```

## 3. Подобрать инструменты (с оговоркой про доступ из РФ)
```
Я [роль] из России. Предложи 3 инструмента, с которых начать, под мои частые задачи: [задачи].
Для каждого: для какой задачи, и помечай доступ — из РФ напрямую / через агрегатор / международный.
Не давай 20 штук. Скажи, что проверить перед использованием. Не выдумывай — если не уверен, так и скажи.
```

## 4. Красные флаги моей профессии
```
Где в работе [роль] ИИ опасен или часто ошибается? Что нельзя ему отдавать и почему?
Особо отметь риски с фактами/числами, персональными данными и ответственностью.
```

## 5. Один ход на эту неделю
```
Исходя из разбора выше: предложи один конкретный ход на неделю — одну задачу из 🟡/🔴, которую я
доведу до результата с ИИ, и что именно я должен проверить сам. Только один ход, не список.
```

## 6. Что мне осваивать
```
Какой один навык мне, [роль], стоит осознанно тренировать в ближайший квартал, чтобы дорожать,
а не конкурировать с машиной в скорости? Объясни почему и как тренировать на реальных задачах.
```

## Что делать с результатами

Перенесите выводы в рабочие листы:
- разложить неделю → [week-inventory](../playbooks/week-inventory.md);
- свести диагноз → [интегральная карта аудита](../playbooks/profession-audit-integrated.md);
- собрать первый ход → [план на 90 дней](../playbooks/personal-90-day-plan.md).

> ⚠️ ИИ уверенно ошибается. Факты, числа, ссылки и оценки — проверяйте. Это материал для размышления,
> не истина о вашей профессии.
